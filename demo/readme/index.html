README studio

Put living characters in your GitHub README. Pick a cast, script what happens (a cursor tour, speech bubbles, mood changes, pokes, naps), then download one SVG file. Everything moves with CSS only, so it works on GitHub, npm and anywhere images are allowed. Nothing to install.
