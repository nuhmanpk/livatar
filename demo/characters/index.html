Create your own

Pick a character and tune it with the controls, no code needed. You get a shareable code, a copy-paste snippet and a PNG/SVG download. Want a brand-new character? Switch to Write code.

A character is a plain object with a render() that returns SVG for a 100×100 box. Mark parts with data-lv-eye, data-lv-mouth, data-lv-body and data-lv-depth and they follow the cursor, blink and show moods.
